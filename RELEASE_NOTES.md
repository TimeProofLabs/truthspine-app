# TruthSpine 0.1.0

TruthSpine keeps your project's Truth current, traceable, and available to every connected agent.

## Start here

1. Download the package for your operating system.
2. Open TruthSpine and connect a real project folder or repository.
3. Open the AI chat, IDE, or agent workspace you normally use.
4. Let TruthSpine guide the connection.

Try TruthSpine free for 14 days. Read the current setup, security, and privacy information at https://truthspine.app/.

## Workspace connectors

- [Install TruthSpine for VS Code](https://marketplace.visualstudio.com/items?itemName=timeprooflabs.truthspine-vscode)
- [View TruthSpine for JetBrains IDEs](https://plugins.jetbrains.com/plugin/33056-truthspine?noRedirect=true)
- Verified VS Code and JetBrains packages are attached as direct fallbacks.
