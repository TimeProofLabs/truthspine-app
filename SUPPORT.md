# Support

For setup help, connector questions, or product problems:

- Search existing [issues](https://github.com/TimeProofLabs/truthspine-app/issues).
- Start a [discussion](https://github.com/TimeProofLabs/truthspine-app/discussions) for questions and ideas.
- Open an issue for a reproducible product problem.
- Email support@truthspine.app when an issue contains private project information.
