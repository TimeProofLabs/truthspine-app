# Security

Please do not report security vulnerabilities in a public issue.

Email **support@timeprooflabs.com** with a clear description, affected version, reproduction steps, and potential impact. TimeProofLabs will acknowledge the report and coordinate follow-up privately.

TruthSpine runs locally and keeps project content local by default. Read the current [security and privacy information](https://timeprooflabs.com/security.html).
